# テスト画像の置き場所

- ファイル名は **テストケースID**（例：`TC01.jpg`）にしてください。対応する拡張子は .jpg / .jpeg / .png / .webp / .heic です
- 撮り方は [docs/03_test_cases.md](../../docs/03_test_cases.md) の各ケースの「画像」欄を見てください
- TC15 は TC01 の画像を、TC20 は TC05 の画像を使い回すので、必要な画像は19枚です
- **顔・住所・名前などの個人情報が写らないようにしてください**（画像は Gemini API に送信されます）
- ネットで拾った画像は使わないでください（著作権の問題があり、実際の撮影条件とも違うため）
