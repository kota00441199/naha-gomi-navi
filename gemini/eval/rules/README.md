# テスト用の品目リスト

那覇市の品目リストは `data/` から自動生成した [prompts/rules_naha_sodai.txt](../../prompts/rules_naha_sodai.txt) を使います（`npm run rules`）。このフォルダには、テスト専用の架空のリストだけを置きます。

## sample-sodai-rules.txt（架空のテスト用リスト）

**実在の自治体のルールではありません。** 「Gemini が渡されたリストだけを使っているか」を確認するために作った、架空の「サンプル市」のリストです（TC18）。

リストの中身はわざとこうしてあります。

- 品目IDを `Z01` のように、那覇市（`S001`〜）と違う形にしている
  → Gemini が那覇市の品目ID（`S011` など）を答えたら、リストではなく前の知識で答えていると分かる
- 椅子は「大きさ・スプリングの有無を問わない」1品目だけにしている
  → 那覇市では「小か大か」の確認が必要な椅子が、サンプル市では `listed` に確定できるはず。リストに合わせて判断を変えられるかを確認できる

## 他の自治体で検証する場合

1. 自治体の**公式サイト**の品目リストを、`data/` と同じ形式の JSON に書き写す
2. 出典URLと取得日を JSON の `source` に書く
3. 書き写した内容は、別のメンバーが公式サイトと見比べて確認する
