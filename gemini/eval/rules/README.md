# 分別ルールファイル

## sample-city-rules.md（架空のテスト用ルール）

**実在の自治体のルールではありません。** 「Geminiが渡されたルールだけを使っているか」を確認するために作った、架空の「サンプル市」のルールです。

ルールの中身はわざとこうしてあります。

- 区分名を「資源A（缶・びん・ペットボトル）」「資源B（紙類）」のように、一般的でない名前にしている
  → Geminiが「資源ごみ」「燃えないごみ」など自分の知識の区分名を答えたら、ルール違反と分かる
- **小型家電のルールを入れていない**
  → 小型家電の写真では `rule_status: "not_found"` になるのが正しい
- 乾電池（R06）は、充電式電池・モバイルバッテリーを対象外と明記している
  → 似た物を区別できるかを確認できる

## naha-city-rules.md（那覇市・本番想定）

那覇市公式ホームページの各分別ページ（2026年10月16日取得）から転記したルールです。出典URLとページの更新日はファイルの先頭に書いてあります。

- **転記者による確認状況**: 公式HTMLのテキストを直接読んで転記した。PDFのチラシ（家庭ごみの正しい分け方・出し方）との照合は**まだしていない**
- **要対応**: 別のメンバーが公式サイトと見比べて確認すること（転記ミスがあると、評価項目7が正しく判定できないため）
- 収集曜日・地域の情報は含めていない（画像認識とは関係がないため）
- ルールが変わった場合（例：令和8年3月から始まったリチウムイオン電池の収集）は、このファイルを更新し、取得日も書き換える

## 他の自治体で検証する場合

1. 自治体の**公式サイト**の分別ルールを、同じ形式（`[ID] 区分 / 対象 / 出し方`）で `rules/<自治体名>.md` に書き写す
2. 出典URLと取得日を、ファイルの先頭に書く
3. 書き写した内容は、別のメンバーが公式サイトと見比べて確認する
