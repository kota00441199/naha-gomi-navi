# 那覇 粗大ごみナビ

那覇市の家庭向け・非公式の処分案内Webアプリ。Next.js / TypeScript / Tailwind CSS。ログイン・有料API・APIキー不要。ブラウザー内で検索・判定を行います。

## 別の端末で開く

GitとNode.js 20.9以上（npmを含む）をインストールしてください。開発・検証環境はNode.js 26.12.0です。

非公開リポジトリの場合は、管理者からGitHubへの招待を受けて承認し、アクセス権のあるアカウントでGitの認証を済ませてください。以下のコマンドだけでアクセス権が付与されるわけではありません。

### 初回：ダウンロードして起動

保存したい場所でターミナル（WindowsではPowerShellなど）を開き、次のコマンドを順番に実行します。

```sh
git clone https://github.com/hikaruhana0514-lang/naha-gomi-navi.git
cd "naha-gomi-navi/ゆきとら-naha-sodaigomi-navi"
npm ci
npm run dev
```

起動したら、同じ端末のブラウザーで http://127.0.0.1:3000 を開いてください。別のポートが表示された場合は、ターミナルに表示されたLocalのURLを開きます。

利用中はターミナルを開いたままにしてください。終了するときは `Ctrl+C` を押します。この起動方法は自分の端末だけで利用するもので、インターネットへの公開は行いません。

### 2回目以降：もう一度起動

ダウンロードした `naha-gomi-navi` フォルダーでターミナルを開いて実行します。すでにアプリのフォルダーにいる場合、`cd` は不要です。

```sh
cd "ゆきとら-naha-sodaigomi-navi"
npm run dev
```

### 最新版に更新

アプリを `Ctrl+C` で停止し、アプリのフォルダーで次を実行します。自分でファイルを編集している場合は、変更をコミットするなどして保存してから更新してください。

```sh
git pull --ff-only
npm ci
npm run dev
```

### 開けないとき

- `git` や `npm` が見つからない：GitまたはNode.jsをインストールした後、ターミナルを開き直してください。
- `Repository not found` や認証エラー：URL、招待の承認、Gitで認証しているGitHubアカウントを確認してください。
- `package.json` が見つからない：`ゆきとら-naha-sodaigomi-navi` フォルダーに移動してから実行してください。
- すでにクローン済み：再度 `git clone` せず、既存フォルダーで「2回目以降」の手順を使ってください。

この手順では親リポジトリ `naha-gomi-navi` 全体をダウンロードします。リポジトリの公開範囲・招待設定は、このREADMEの追記では変更していません。

## 開発・検証用コマンド

アプリのフォルダーで実行します。

```sh
npm test            # 判定・検索・集計の17テスト
npm run typecheck   # TypeScript検査
npm run build       # out/ に静的サイトを出力
npm start           # Python 3で out/ をローカル配信
```

ブラウザーテスト（別ターミナルで `npm start` 実行中）：

```sh
npm run test:e2e
```

テストはインストール済みGoogle Chromeを利用します。Chromeがない環境ではPlaywrightのブラウザーを導入し、playwright.config.tsのchannel指定を変更してください。本番は `out/` を静的ホスティングへ配置でき、サーバーAPIは不要です。今回の成果物はローカルプロジェクトです。

## 実装

- 表記正規化（NFKC、かな、長音）、別名検索、候補選択、該当なし時の問い合わせ導線
- 18品目の確認済みデータ。ソファー・マットレス・机・学習机セット・自転車・電動自転車・電子レンジ・タンス・テレビ台・家電4品目・PC・フライパン・ピアノ・タイヤ・耐火金庫
- 家庭/事業所、数量、品目ごとのスプリング・人数・袋・バッテリー・寸法・重量の質問
- 7種類の処分区分、体積/重量境界、品目別料金、概ね50kg/5m制限
- 専用券・通常券の区別と枚数、単価・数量・小計、未確定品目と確認済み分の小計
- クレジットカード/PayPayと処理券の排出手順の切替
- 公式申込・説明・電話への導線。予約/決済は公式側のみ
- レスポンシブ表示、フォームラベル、radio/fieldset、キーボード、フォーカス移動、検索結果通知、読み込み・エラー画面

## 構成

- `src/lib/data.ts`：品目、別名、ルール、質問、手順、注意、出典・確認日・確認状態
- `src/lib/engine.ts`：検索・決定論的判定・料金・集計・支払別手順
- `src/app/page.tsx`：検索→質問→結果の画面
- `src/app/globals.css`：スマートフォン優先の表示
- `tests/engine.test.ts`：料金境界値・分類・集計テスト
- `tests/ui.spec.ts`：ブラウザー操作・画面幅の回帰検証
- `SOURCES.md`：調査元・取得失敗・保守の記録

## 制約

- すべて見積もりです。外寸体積は目安であり、形状や公式品目別条件、収集可否は公式受付で確認してください。
- 重量や寸法が不明なら収集制限の確認も未完了です。重量は推測しません。
- 未登録品目、家電リサイクルのメーカー別料金、PC回収条件、袋代は自動算定しません。0円にせず要確認として残します。
- フライパンの通常ごみ判定は、指定袋に入り、重量10kg以下を入力した場合に限ります。それ以外は問い合わせに留めています。
- 公式の取扱所ページ取得失敗を明示。専用券は市のPDFへ、通常券は受付トップの「取扱所」へ進む導線です。
- 確認済みデータは2026-10-17時点。検索時の再取得・自動更新はしません。更新手順はSOURCES.md参照。
- 入力・見積もりはページを開いている間だけ保持。再読み込みで消えます。
- 予約・決済・収集日の連携、写真認識、ログインは実装していません。
