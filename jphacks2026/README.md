# すっきり回収ナビ!

## 概要

「すっきり回収ナビ」は、沖縄県那覇市の粗大ごみ処分をサポートするWebアプリケーションです。

処分したいごみの検索や、必要な処理券の確認、収集予定の管理などを通して、粗大ごみの処分をスムーズに行えるようにします。

## 主な機能

- **ごみの検索**：処分したいごみの名前から検索できます。
- **カテゴリ別検索**：ごみをカテゴリごとに探せます。
- **質問による判定**：品目ごとに必要な質問を一問ずつ確認し、わからない場合も選択できます。
- **収集可否の確認**：料金とは独立して、重量・長さなどの条件から収集可否を確認できます。
- **処分方法・料金の案内**：回答内容から、処分区分、必要な処理券、単価、数量、小計を案内します。
- **処分リストの管理**：処分するごみをリストに追加し、回収状況を管理できます。
- **処理券の確認**：登録したごみに応じて、必要な処理券の種類・枚数・金額を確認できます。
- **収集予定の登録**：収集日や回収場所を登録できます。
- **公式申込への導線**：確認した内容から、那覇市の公式申込・説明・電話窓口へ移動できます。
- **入力内容の保存**：入力途中の内容や結果を端末内に保存し、再計算して復元できます。
- **スマートフォン対応**：スマートフォンでも利用しやすいレイアウトを目指しています。

### ゆきとら担当の機能

那覇市の粗大ごみ案内では、次の流れで品目ごとの処分方法を確認できます。

1. 品目を検索して候補を選択する
2. 数量、品目の仕様、重量・大きさなどの質問に回答する
3. 収集可否と料金を分けて確認する
4. 処理券や支払方法を確認し、公式申込へ進む

数値がわからない場合は推測せず、確認が必要な条件として表示します。判定結果と入力途中の内容は同じ端末のブラウザーに保存されますが、予約・決済・収集日の登録は公式側で行います。

## 起動方法

### 1. リポジトリをクローンする

```bash
git clone https://github.com/hikaruhana0514-lang/naha-gomi-navi.git
```

### 2. プロジェクトのディレクトリに移動する

```bash
cd naha-gomi-navi
```

### 3. 依存パッケージをインストールする

```bash
npm install
```

### 4. 開発サーバーを起動する

```bash
npm run dev
```

ターミナルに表示されたURLをブラウザで開くと、アプリを利用できます。

## 開発について

このプロジェクトは、React と TypeScript を用いてフロントエンドを開発しています。

画面のスタイリングには Tailwind CSS を使用し、React Router によって画面遷移を管理しています。
